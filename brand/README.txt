FITAPP LOGO PACKAGE / DESIGN DIRECTION 01 / V1.0

The master logo is svg/fitapp-logo-primary.svg. Its paths are outlined and
do not depend on installed fonts. Each production SVG uses filled paths.
SVG files are editable in Figma, Illustrator, Inkscape and web projects.

CONTENTS
svg/ - primary, black and white lockups; symbols; wordmark; square app icon.
png/ - transparent 2400 px lockups, 1024 px symbols, square app icon and favicons.
specifications/ - exact geometric data and the symbol construction SVG.
Fitapp_Logo_Guidelines.pdf - measured construction and usage rules.

MEASUREMENTS
Base module u = 4. Symbol bounds 112 x 96. Main band thickness 16.
Minimum outside clear space 24. Symbol-to-wordmark gap 24.
Recommended digital minimums: symbol width 24 px; lockup width 128 px.
16 px favicon is provided for browser contexts where the size is fixed.
The app icon is an opaque square source; the consuming platform/UI applies corners.

TYPE ORIGIN
Wordmark: Rubik Bold by Hubert & Fischer, with optical spacing adjustments.
The included artwork contains glyph outlines, not font files.
Rubik font metadata identifies the SIL Open Font License, Version 1.1:
http://scripts.sil.org/OFL
No proprietary font purchase is required to place these outlined SVG logos.

COLOR
Teal #087F72; deep ink #142D29; soft mint #CDEEE3; paper #F7FAF7.
These are RGB/HEX digital masters. Print color conversion depends on the
production process and should be proofed with the print supplier.

The graphic is a first developed design direction for review.
